Guardian Anti-Money Laundering Detection — v1.0

Welcome to Guardian AML

Guardian is an ML-powered Anti-Money Laundering detection system running on LinuxONE servers. Use the sidebar to navigate between inference tools, or click a card below to jump directly to an endpoint.

⊞
Batch Random Inference
Randomly sample N accounts from the dataset and run AML inference across all of them.
POST /inference/batch-random
→
Target Account (From)
Analyze all outgoing transactions sent from a specific bank account.
POST /inference/target-account/from
←
Target Account (To)
Analyze all incoming transactions received by a specific bank account.
POST /inference/target-account/to
⇌
Target Account (Both)
Analyze all transactions — both incoming and outgoing — for a specific account.
POST /inference/target-account
▲
Top Risky Accounts
Find the N highest-risk accounts within a bank using Bayesian-smoothed risk scoring.
POST /inference/bank/top-risky-accounts
≡
Bank Summary
Get bank-wide AML risk statistics: flagged count, flagged value, and average risk probability.
POST /inference/bank/summary
